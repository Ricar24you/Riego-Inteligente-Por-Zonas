# Guion de demostración (8–10 minutos)

1. Explicar el problema, límites del simulador y árbol OTP (1 min).
2. Mostrar `rebar3 compile` y `rebar3 eunit` en vivo (1 min).
3. Mostrar 12 zonas, crear trabajos, describir prioridades y límite 3; usar las pruebas del modelo para ventana nocturna sin cambiar el reloj del sistema (2 min).
4. Activar lluvia, inyectar fuga, mostrar alarma y reconocimiento. Simular válvula atorada y explicar aislamiento conceptual de bomba (1 min).
5. Ejecutar prueba OTP que mata controlador y válvula; mostrar logs de supervisión y recuperación de cola. No confundir prueba de proceso con un corte físico de alimentación (1 min).
6. Mostrar métricas, API y actualización WebSocket (1 min).
7. Mostrar arquitectura, manual y matriz de evidencias. Presentar por separado las pendientes Pi/Stitch/Gist; no afirmar ejecución remota ni origen Stitch sin evidencia (1 min).

Para obtener puntos de UI Stitch: completar exportación e integración descritas en design/PROMPT_STITCH.md y capturar dashboard, detalle e historial reales en móvil y escritorio. Para ejecución autorizada: grabar la misma demostración en la Pi cuando SSH esté disponible.
